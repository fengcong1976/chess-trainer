## 功能特性

### ♟ 人机对弈
- 与开源最强象棋引擎 **Pikafish** 对弈（未安装时自动回退内置迭代加深引擎）
- 5 级难度可调（入门 → 大师级思考时间）
- **AI 着法建议**：随时点"💡 建议"查看引擎推荐的最优走法
- **对方意图提示**：点"🔍 对方意图"看看对手下一步想干嘛
- 认输 / 求和（引擎评估后决定接受或拒绝）

### 🎓 残局训练（37 题 · 一步杀 / 困毙）
- 精选杀法残局，覆盖双车错、马后炮、铁门栓、闷宫、重炮、车兵/马兵/炮兵 等 20+ 种形态
- **精确杀棋求解器**（minimax 穷举）判定，与引擎强弱无关，100% 准确
- 提示 → 看解法 → 通关讲解三级递进，每一步都有中文记谱（炮二平五）
- 错题自动收集，点"📌 错题复习"针对性巩固

### 📖 开局训练（课程化教学）
- 多门课程：当头炮、屏风马应对、飞相局、仙人指路、铁滑车识破 等
- 支持红 / 黑双视角；每步判定是否吻合主线，走偏即弹出正着纠正与讲解
- 教练按谱自动应招，"演示"按钮看完整谱摆子
- 支持导入 **Xiangqi Polyglot .bin 开局书** → 自动拆成新课

### ⚔ 中局战术训练
- 捉双、闪击、牵制、引离、弃子入局 等经典中局战术
- 逐线判定 + 偏着演示，走对了才进入下一题

### 🎯 基本杀法训练
- 重炮、马后炮、卧槽马、钓鱼马、挂角马、双车错、天地炮、大刀剜心、困毙 等 30 种杀法分类训练
- 每种杀法都有口诀 + 图解 + 实战应用场景

### 🧠 思维口诀（29 条）
- **开局原理**（6 条）：出车跳马架炮、炮不轻发、士象补中…
- **中局战术**（8 条）：捉双、闪击、牵制、双马连环、马踏八方勿蹈边…
- **残局原则**（9 条）：**残棋炮归家**、**马不蹈边**、车怕低头将怕高、缺士怕双车、单车寡炮难成巧…
- **杀法要诀**（6 条）：象棋十诀、飞将规则、困毙原理…
- 支持全屏查看，字号同步放大

### 📅 每日训练计划
- 可视化每日打卡（残局 N 题 + 开局 N 步 + 实战 N 盘）
- 训练战绩持久化（胜/负/和 + 胜率）

## 安装与运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

> 依赖非常简单：`PySide6 >= 6.6.0`

### 2. （推荐）放置 Pikafish 引擎

Pikafish 是当前最强的开源象棋引擎：

- 仓库地址：https://github.com/official-pikafish/Pikafish
- 下载 Windows 版本后，将 `pikafish.exe` 和 `pikafish.nnue` 放入 `engine_bin/` 文件夹

> 没有 Pikafish 也能跑——自动回退内置引擎，入门对弈足够用。

### 3. 启动

```bash
python main.py
```

### 4. 打包 exe（可选）

仓库根目录已有 `中国象棋培训大师.spec`，PyInstaller 一键打包：

```bash
python -m PyInstaller --clean --noconfirm "中国象棋培训大师.spec"
```

产物：`dist/中国象棋培训大师.exe`（onefile 单文件，约 85 MB，含引擎+音效）

## 技术亮点

- **精确杀棋求解器**：minimax 穷举 + 2M 节点预算，`forced_mate_depth` / `find_mate_in_one` 覆盖将军杀和困毙两种形态
- **开局合法走法校验**：perft 校验开局 44 种合法走法，100% 正确
- **残局安全设计**：炮架稳定（己方棋子当炮架，对方无法移开）、起始无将军、无飞将违规
- **运行时路径解析**：兼容开发模式（项目根）和打包模式（exe 旁），`resources.py` 统一出口
- **复盘引擎评估**：逐半步 UCI `position + eval`，优势曲线 QLinearGradient 渐变填充
- **中文记谱系统**：`notation.py` 红方中文（炮二平五）、黑方阿拉伯（炮 8 平 5），UCCI ↔ 记谱双向转换
